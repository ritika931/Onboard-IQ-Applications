# OnboardIQ Applications – clickable prototype

Single-file HTML prototype of the OnboardIQ Applications page (ironbank-face dashboard):
listing table, full applicant details page, CSV export with column picker, and Export logs.

- Open `index.html` in a browser, or view it on GitHub Pages.
- All data is synthetic (generated in the FKW MIS schema). No real applicant data.
- Use **Prototype controls** (bottom-left) to simulate large exports, failures, blocked downloads and file expiry.
- Use **Edit text** (top-right) to change copy inline.
